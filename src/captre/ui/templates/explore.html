Explore Attestations

Look up any attestation by its UUID or content hash. Records are stored directly in Algorand Box Storage — no intermediary required.

How to browse

Finding records

Algorand Box Storage does not support enumeration — boxes are addressed by key. To retrieve an attestation you need its attestation_id or content_hash, both of which are returned when you call POST /attest.

UUID
By attestation ID
Use the UUID in the attestation_id field of the POST /attest response. 
GET /attestation/{id}
HASH
By content hash
Pass the exact hash string used when attesting to check current status. 
GET /verify?content_hash=sha256:…
Response shape

What an attestation looks like

JSON response
{
  "attestation": {
    "attestation_id": "a00fe88e-…",
    "author":         "GFYF3KDN…",
    "content_hash":   "sha256:abc…",
    "status":         "active",
    "created_at":     "2025-01-01T00:00:00Z",
    "tx_id":          "QK5ATJTD…",
    "agent_id":       "my-agent-v1",
    "output_type":    "file",
    "tags":           ["research"]
  },
  "verified": true
}
Author binding

The author field is the Algorand address that paid for the attestation via x402 — cryptographically bound to the payment transaction. It is never the Captre service account.

Trust model

You can verify any attestation directly against any Algorand node without going through Captre — the data is in Box Storage, readable by anyone.
